Third-party notices for com_appointments
========================================

This file lists third-party code shipped with the component, with its source,
version and licence. Each listed licence is compatible with the component's
GPL-3.0-or-later. Upstream copyright notices are kept unchanged in the files.

CalDAV libraries
----------------

Folder: administrator/components/com_appointments/lib/

The CalDAV server of the internet calendars uses sabre/dav and its
dependencies. They are bundled with every PHP symbol moved below the namespace
Advans\Component\Appointments\Vendor\ (php-scoper), so the copy never collides
with another extension that ships the same libraries. Apart from that prefix,
Joomla's guard against a direct call (defined('_JEXEC') or die) at the top of
each file, and the omission of parts the component never loads (the SQL storage backends,
CardDAV, the HTML browser plugin, the file system nodes and the command line
tool), the code is the unchanged upstream release. Each library folder holds
the upstream licence text in LICENSE. tests/tools/sabre/ in the source
repository regenerates the folder from the pinned versions below.
